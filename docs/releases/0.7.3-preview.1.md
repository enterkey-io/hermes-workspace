# 0.7.3-preview.1

Direct pebble chats now support native Hermes reactions. React from a message's
smile-plus button, change your emoji in the picker, or click your reaction to
remove it. Agent reactions appear live and both authors' reactions survive
refreshes. Your reaction reaches the agent on its next turn; reacting itself
does not start a model request.

The integration enables native feedback for the opened profile and provides a
verified `pebble_react` tool to enrolled pebbles. Existing personality, model
settings and memories are preserved. Crew reactions remain unavailable because
the supported Hermes group API has no native equivalent.

The PWA icon now uses an enlarged pebble cropped into the bottom-left, looking
up-right. Public asset caching advances to the corrected icon. Operating systems
may retain a previously installed home-screen icon until they refresh it.

Update the combined plugin and sync enrolled runtimes using the tagged
[agent guide](../AGENT_INSTALL.md). Existing login, data, origin and ports stay
in place. No new pairing or manual per-agent configuration is required.

Validation uses synthetic local infrastructure: production desktop and phone
flows, native owner onboarding/chat/reload, and a two-way reaction round trip on
both pinned Hermes builds. No owner model, persona, credentials or live home is
used for these checks. This remains a preview release.
