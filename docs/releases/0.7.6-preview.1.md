# 0.7.6-preview.1

Add existing agent and Create pebble now expose Reports to, responsibilities,
boundaries and expected outputs, alongside the existing name, handle, avatar,
title and description. Edit uses those same controls. Role and reporting choices
save through Hermes; invalid reporting cycles are rejected before enrollment or
native writes. Existing two-field clients remain compatible.

The welcome option now says **Send me a welcome message**. It asks the pebble to
send its first message using its existing personality and model. Opting out
does not submit a prompt.

Returning after a background connection interruption preserves open setup,
unsaved fields, manager choices and the visible conversation. Automatic recovery
uses the connection status instead of a red chat error banner. Actual operation
errors retain their own message and now wrap inside a bounded notice.

The sidebar is wider on desktop and phones; its header separates Search, New
and Close with full touch controls. This release includes the standalone emoji
reactions from 0.7.5: no border, background or shadow.

Validation covers the production desktop and iPhone WebKit/Android Chromium
flows, native owner acceptance with an isolated Hermes home and localhost model,
plugin tests and installed-package acceptance. The new browser cases interrupt
connections during both setup flows, retain message elements, test reporting
persistence and measure sidebar width/control separation. Physical-device and
owner visual acceptance remain separate.

Use [the agent upgrade guide](../AGENT_INSTALL.md#updates-and-rollback). Preserve
state, URL and login; synchronize runtime copies before activation. Confirm the
served `/version.json` reports this release, then reload or reopen the browser
once to load the updated screens. Upgrade verification sends no model prompts.
