# 0.7.4-preview.1

The phone composer centers its single text line beside the touch controls.
Reactions overlap the lower-left edge of a message in a compact badge; their
touch target stays large without drawing a large circle.

Replies retain their displayed time and action controls when Hermes commits
them. Reaction events update their addressed message directly, without fetching
partial history into a live streamed reply. Roster polling also defers transcript
replacement until the turn completes.

Agents receive the native discovery instructions for `pebble_react` when that
capability is enabled. Existing saved CLI tool selections receive the plugin's
workspace toolset when that Pebble's chat opens. Other toolsets, model settings
and persona files are preserved. Native acceptance describes the deferred tool
before calling it, including with catalog listings disabled, on both pinned
Hermes builds.

Update the combined plugin and enrolled runtime copies together, while native
work is idle, following [the agent install guide](../AGENT_INSTALL.md#updates-and-rollback).
Activate the new release after synchronizing the copies so its new native
process loads them. Keep the existing login and URL; no pairing or onboarding is
required. Installation and verification do not run the owner's models.

This remains a preview. Validation uses disposable homes and a localhost model,
production desktop/phone browser flows, and installed-package acceptance. It
does not certify every physical phone or the owner's specific model behavior.
