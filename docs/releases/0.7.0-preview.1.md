# Pebble Crew 0.7.0-preview.1

Integration 0.7.0. This is a development preview; owner acceptance and host-specific
production checks remain separate from local verification.

- Shared shadcn/Radix controls, theme and motion across actual app routes.
- Docked details, fixed editor geometry, quiet dark menus/scrollbars and explicit
  focus restoration. Header hover moves the arrow without adding a background.
- Owner messages capped at 50% width; darker pebble replies. Immediate message time,
  stable receipt correlation, separate Copy icon and a minimal Thinking/Working shimmer.
- Persistent custom sections and Crews, move/reorder controls and native Crew chats.
- Owner-local visible-history, routine and supported sent-file search with typed
  result previews, identity revalidation and disclosed limits. No external index.
- New shapes Cairn, Seed, Dune, Flint and Drift; new colors Umber, Moss, Ocean,
  Heather and Sienna. Existing appearances and photos remain available.

## Upgrade

Use the [matching agent guide](../AGENT_INSTALL.md). Verify SHA256SUMS and manifest,
back up only code for rollback, install the full combined plugin, then run its
update/public verification and sync-runtime commands under the existing supervisor.
Preserve administrator/login keys, sessions, native stores, local file/presentation
state, origins, ports, routes and enrolled identities. No pairing, new account,
placeholder agent or model prompt is needed for an installed owner.

## Verification boundaries

Actual app browser flows and the independent Astra review use synthetic data.
Native gateway checks use unmodified pinned Hermes 0.21.0/0.21.7 sources and a local
deterministic model. They establish native Bot Mode execution, not provider quality.
Search native probes use isolated read-only session databases. Full Linux desktop
startup, all hardware/browser performance and the owner's installation remain
host-specific checks. Group attachments/generated-file indexing remain deferred.
