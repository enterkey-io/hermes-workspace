# 0.7.5-preview.1

Phone sidebar menus sit at the right edge of their pebble row or pinned tile,
with 44-pixel touch controls. Reactions are standalone emoji overlapping the
lower-left edge of the message, without a border, background or shadow.

Settings > Connections now opens a compact service list for the selected pebble.
Each service has a focused detail view for sign-in, API keys and tool access.
Add connection opens a searchable catalog. Long tool lists keep the service
name and Save control visible while scrolling.

Discovery preserves Hermes tool settings. Explicit tool edits require Save;
navigation protects unsaved edits. Saving an API key preserves a tool draft,
failed saves do not claim success, and completed sign-in refreshes the service
list and native tool policy. OAuth and API-key controls follow the actual
service's authentication method.

Validation includes production desktop and iPhone WebKit/Android Chromium flows,
settled screenshot review, native owner acceptance in a disposable home, and
installed-package acceptance. Browser tests check actual touch-control geometry,
popover bounds, reaction appearance, authentication, credential failures,
permission persistence and scroll containment. They do not establish visual
acceptance on every physical device.

Update using [the agent install guide](../AGENT_INSTALL.md#updates-and-rollback).
Preserve the owner state, URL and login; synchronize enrolled runtime copies
before activating the release. Installation checks do not run owner models.
