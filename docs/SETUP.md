# Set up your private workspace

Give your Hermes agent the [plugin installation guide](AGENT_INSTALL.md). The
plugin includes the web app and login. Your agent installs it on your existing
Hermes host, sets up persistent startup and HTTPS access, verifies the connection,
and gives you **one private setup link**.

Open that link, create your administrator login, and confirm your detected primary
agent's @ handle and animated or photo avatar. The same Hermes personality,
memories, skills and settings remain in place. There is no address field, token
entry or pairing conversation.

Use the plain app URL on later visits. Sign in when needed; Hermes reconnects
automatically. Add other existing agents in the app, organize crews, edit roles and
appearances in Settings, and review agent management requests there.

The setup link is a temporary private credential. Keep it out of public issues or
reports. Your agent should keep native history, personality, credentials and app
login keys on your infrastructure. Olares is simply one possible host running
Hermes. Independent web hosting remains an optional advanced deployment.

## Install on your phone or computer

Open your own HTTPS app URL. In Safari on iPhone, use **Share → Add to Home Screen**
and open it from the Pebble Crew icon. In Chrome or Edge, choose **Install app**
from the browser menu. The installed app uses your existing Hermes host and login.

An internet or tailnet connection to your host is still needed. Offline mode
shows a reconnect screen; chats, files and credentials are never put in the
app’s offline cache.
